## 卡片结构

正面在空后用括号给出原形：动词给**未完成体 – 完成体**一对不定式，其他词给原形。
语法要求放在「提示」开关里，**默认关闭**；需要时再打开，关掉后只剩句子和原形。

卡背有**两种解释**，学习时点卡片右上角的「简洁 / 详细」随时切换，选择会记住：

- **简洁**：整句补全＋一行规则，适合快速过。
- **详细**：再加中文翻译、解析、易错点，适合第一次学。

正面：

```
У нас мало времени. ______ второе упражнение.
提示：не делать · 未完成体将来时否定
```

背面：

```
У нас мало времени. Не будем делать второе упражнение.   ← 答案在句中高亮
我们时间不够，就不做第二个练习了。
规则 · не + 未完成体将来时表示“将不会进行某行为”。
解析 · 这是“决定不做”，不是“做不了”。
易错 · 用 «не сделаем» 会变成“做不完/做不到”。
```

## 数据格式

```js
window.GRAMMAR_UNITS.push({
  id: 'u08', n: 8, lesson: 5, page: 106,
  group: '词法', kind: '动词体',
  title: '动词过去时体的意义和用法',
  short: '反复 / 持续 / 结果',
  concept: '……',
  points: ['……', '……'],
  cards: [{
    q: 'Антон ___ новые слова за час.',   // 用 ___ 表示挖空
    hint: 'выучить · 完成体过去时',
    a: 'выучил',
    full: 'Антон выучил новые слова за час.',
    zh: '安东一个小时就背会了生词。',
    rule: '完成体 + за сколько 表示在若干时间内做完。',
    note: '……',
    trap: '……'
  }]
});
```

新增卡片只改 `data/uNN.js`；`lessons.js` 会自动把它并进对应课。

## 版本

版本数据在 `data/versions.js`，界面徽章、首次打开的更新弹窗、`#/changelog` 更新日志都读这一份。

- 升版：在数组最前面加一条（`v`、`date`、`title`、`items`），徽章和弹窗自动更新。
- 同时把 `sw.js` 里的 `CACHE` 改成新版本号，避免离线缓存读到旧的 JS。
- 当前：**Alpha v0.1**（首个可运行版本）。
